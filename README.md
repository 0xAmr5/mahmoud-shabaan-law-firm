## 📌 نبذة عن المنظومة (Overview)

منصة رقمية احترافية صممت خصيصاً لمكتب **الأستاذ / محمود شعبان داخلي** للمحاماة والاستشارات القانونية، تجمع بين واجهة تقديمية سينمائية رصينة، ونظام إدارة داخلي متقدم متعدد الصلاحيات (Admin, Lawyer, Client Portal).

---

## ✨ المميزات الرئيسية (Key Features)

### 🏢 1. لوحة تحكم الإدارة العليا (Admin Dashboard)
* **إحصائيات وتقارير حية:** مراقبة عدد القضايا المتداولة، جلسات المحاكم القادمة، ومعدلات إنجاز المهام.
* **إدارة ملفات الدعاوى:** تنظيم أرقام القضايا، الدوائر، التوكيلات، والمحامين المسؤولين.
* **إدارة فريق العمل والموكلين:** تخصيص صلاحيات الوصول ومتابعة حسابات المحامين.
* **أجندة ورول الجلسات:** تنبيهات فورية بمواعيد الجلسات والقرارات الصادرة.

### ⚖️ 2. لوحة عمل المحامي المسؤول (Lawyer Workspace)
* **سجل الحضور والانصراف الذكي:** إثبات الحضور ومتابعة ساعات العمل اليومية.
* **متابعة القضايا والتايم لاين:** تسجيل الدفوع وتحديث الجدول الزمني للدعوى لحظياً.
* **تكليفات المهام:** إدارة المهام الموجهة وتغيير حالات التنفيذ.
* **شات مباشر ومحمي:** تواصل فوري مع الموكلين وإدارة المكتب.

### 👤 3. بوابة الموكل الإلكترونية (Client Portal)
* متابعة الجدول الزمني لمراحل وتطورات الدعوى بشفافية تامة.
* استعراض القرارات القضائية ومواعيد الجلسات القادمة.
* تحميل صور ومستندات الدعوى المصرح بعرضها.
* محادثة مباشرة مع المحامي المختص.

### 🌐 4. الموقع التعريفي العام (Public Showcase)
* تصميم ليلي ملكي (Slate & Amber Glassmorphism) متجاوب بالكامل مع كافة الشاشات.
* استعراض مجالات العمل والخدمات القضائية.
* نموذج حجز ومتابعة الاستشارات القانونية وربطها بـ Firestore والواتساب.
* ركن تعريفي بهوية المطور وقنوات التواصل.

## 🛠️ البنية التقنية (Tech Stack)

* **Frontend:** React 18, Vite, React Router DOM
* **Styling & UI:** Tailwind CSS, Lucide React Icons
* **Backend & Cloud:** Firebase Authentication, Cloud Firestore
* **Storage:** Cloudinary Auto Media Engine
* **Form & Validation:** React Hook Form, Zod
